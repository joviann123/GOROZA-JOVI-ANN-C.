## Analysis Questions

### Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of cloud services with over 200 fully featured services globally. Its early launch in 2006 gave it a significant head start in developing deep and mature capabilities across infrastructure, databases, and analytics.

### Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the best integration with Microsoft technologies as it natively supports Windows Server, Active Directory, and Office 365. Organizations already using Microsoft software can seamlessly extend their existing licenses and infrastructure to Azure.

### Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest in Artificial Intelligence and Kubernetes because Google originally created Kubernetes and continues to lead in open-source container innovation. Additionally, GCP offers industry-leading AI/ML tools such as Vertex AI and specialized TPU hardware.

### Which cloud platform would you personally choose and why?
I would personally choose Amazon Web Services (AWS) because of its comprehensive documentation, massive global market share, and extensive community support. Its mature platform makes it an ideal environment for learning industry-standard cloud architecture principles.
