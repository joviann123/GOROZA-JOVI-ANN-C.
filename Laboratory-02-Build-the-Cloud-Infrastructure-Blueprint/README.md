# Laboratory 02: Build the Cloud Infrastructure Blueprint

## Mission Overview
This project simulates the initial technical assessment phase for an enterprise cloud migration strategy. The primary focus centers on auditing active server configurations, tracking hardware variables within a live cloud instance environment, and creating technical architecture documentation.

## Objectives
* Discover and document underlying Linux hardware allocation matrices.
* Conceptualize the foundational four-pillar cloud infrastructure dependencies.
* Map operational structural terminology variations across AWS, Azure, and GCP.
* Author clean technical repository documentation using standard Markdown protocols.

## Cloud Infrastructure Components Covered
* **Compute Layer:** Engine workloads and dynamic processing units.
* **Storage Layer:** Non-volatile file blocks and media repositories.
* **Network Layer:** IP address spaces, routing boundaries, and connectivity paths.
* **Identity Management:** Role access permissions and secure resource policies.

## Tools Used
* **Terminal System:** KillerCoda Playground Environment
* **Platform Control:** Git & GitHub Document Management Systems
* **Design Canvas:** Excalidraw / Draw.io
* **Documentation Engine:** Markdown Syntax
