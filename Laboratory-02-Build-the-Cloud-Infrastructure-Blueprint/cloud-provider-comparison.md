### Guide Questions & Analysis

#### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) currently offers the broadest range of public cloud services across the market. As an early industry pioneer, it maintains an extensive portfolio covering edge computing, deep database engines, and niche specialized deployment environments.

#### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is highly recommended for legacy enterprise systems heavily dependent on Microsoft architectures. It features native compatibility matrices, unified software licensing structures, and seamless integrations with enterprise frameworks like active directory systems.

#### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized as an industry leader for high-efficiency container orchestration and advanced data modeling toolkits. Because Google originally engineered the baseline Kubernetes architecture, their cloud infrastructure remains exceptionally optimized for container clusters and scalable machine learning frameworks.

#### 4. What similarities did you observe among the three cloud providers?
All three leading cloud providers share identical fundamental abstractions under their unique brand names, offering scalable virtual machines, elastic block storage, isolated private networking planes, and rigorous identity controls. They all utilize pay-as-you-go consumption models built over massive, globally distributed underlying hardware hypervisors.
